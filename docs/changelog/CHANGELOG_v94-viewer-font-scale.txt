PDF校正ツール v94 - ビューアフォント拡大
更新日: 2026-07-13

- 指摘レポートの既定 root font-size を 15px から 16pxへ拡大。
- 補助テキストを含む通常表示の最小文字サイズを 12.5pxへ統一。
- 一覧要約を16px、行高を40px、チェックボックスを18pxへ拡大。
- 詳細要約を17px、原文・修正案を15px/行間1.6へ拡大。
- メタ、件数、ページタブ、ガイドを13.5pxへ拡大し、文字色を #4B4B50へ調整。
- A− / A / A+ を 0.9 / 1.0 / 1.12 に変更。
- 印刷時は従来相当の15px基準を維持。
- DOM構造、選択連動、フィルタ、印刷処理、解析パイプラインは変更なし。

検証:
- 生成テンプレートおよび生成後モジュールの構文検査を実施。
- 1600x900 / 1280x800 の表示条件をCSS寸法で確認。
- 実データを用いたブラウザ撮影は、この作業環境に第9回出力データがないため未実施。
