v94 空白のみ差分（体裁指摘）の既定除外

- quote / suggestion から半角・全角空白、タブ、改行、NBSP、ゼロ幅文字だけを除いて一致する指摘へ excluded_reason=ws-only-diff を付与。
- 通常一覧・件数・ページ注記・確認進捗から既定除外し、「体裁指摘を表示（N件）」をONにした場合のみ一覧末尾へ表示。
- 大文字小文字とソフトハイフンは正規化しないため、それらの差分は除外対象外。
- 体裁指摘の要約・理由を機械生成文へ差し替え、モデルの要約・理由は参考欄へ移動。
- JSON/CSVには全件を維持し、excluded_reasonとmodel_reasonを追加。書き出しHTMLにも既定OFFの表示トグルを追加。
- プロンプトへ「( (71.6) %)」→「((71.6)%)」を出力しないネガティブ例を追加。

検証: HTML内JavaScript構文、server.js構文、ZIP整合性、空白のみ・大文字小文字・ソフトハイフンの判定コードを静的確認。Windows上での実ZIP再取り込みは未実施。
