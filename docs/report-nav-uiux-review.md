## 2. 現状の操作フロー

### フローA: 英語版（校正対象）の指摘を、日本語版（比較資料）と照らし合わせる

1. 右の指摘を選ぶ（または →）。左に英語PDF、該当箇所が黄色。
2. 右ペインの詳細を下へ見ていき、`理由・詳細` の最下段にある `[日本語版 P.12 を見る]` を押す。
3. （初回のみ）REF の base64 復号と PDF.js 読み込みを待つ。**読み込み中の表示は無い**。
4. 左が日本語PDFに入れ替わる。ラベルは `比較資料 P.12`、青枠。スクロールは先頭に戻ってから青枠へ寄る。
5. 英語側をもう一度見るには、左ペイン最下部の小さな `[校正対象に戻る]` を押す。スクロールはまた先頭に戻ってから黄色枠へ寄る。
6. 2〜5 を必要なだけ繰り返す。
7. → で次の指摘へ。**表示は必ず英語側に戻る**ので、次の指摘でも 2 からやり直し。

→ 指摘1件あたり、比較は最低でも「右下のボタン → 左下のボタン」の往復が要り、マウスは対角線上を行き来する。キーボードだけでは完結しない。

### フローB: 整合性指摘で、対象PDF内の2ページ（例 P.12 と P.8）を見比べる

1. 指摘を選ぶ → P.12 が黄色。
2. 詳細上部の `[P.8 も表示]` を押す → P.8 に相手側の矩形。
3. P.12 に戻るボタンは **無い**。同じ指摘をもう一度クリックするか、← → で前後してから戻る。後者だと別の指摘を経由してしまう。

## 4. 改善案（優先度つき）

優先度: **P0** = 小さな変更で毎回の操作が楽になるので最初にやる / **P1** = 効果は大きいが設計が要る / **P2** = あると良い。

### P0-1 PDF ツールバーに「表示する文書」の常設トグルを置く（F1, F2, F3, F10）

```
.pdfbar:  [ 校正対象 EN | 比較資料 JA ]   ◀ P.12 / 40 ▶   [縮小][拡大][標準][幅]   ↩ 戻る
```

- 2 択のセグメントボタン（`role="radiogroup"`、`aria-pressed`）。選択中の指摘に REF が無いときは比較資料側を `disabled` にし、`title="この指摘には比較資料の対応箇所がありません"` を付ける。
- REF 表示中は **PDF 枠全体の色を変える**。例: `.page-pane[data-view="ref"]` で `.pdfbar` に青の下線、`#pdfWrap` に薄い青背景と左端の太線。色は既存の `.ref` 枠色（`#3b6f96`、`:9803`）に合わせる。
- 呼び名をそろえる。`DATA` に `target_language` / `reference_language`（書き出し時に分かっている判定結果。`index.html:2273` 付近）と REF のファイル名を入れ、トグル・ページラベル・詳細ボタンで同じ文言を使う。固定文字列「日本語版」（`:10108`）はやめる。言語が分からないときは「校正対象／比較資料」。
- REF が複数あるときは、トグルの右半分を `比較資料 ▾` のドロップダウンにする。
- 今の `[校正対象に戻る]`（`#pdfHint` 内）は、トグルに置き換えて消す。

### P0-2 切り替えのキーボードショートカット（F5, F15）

| キー | 動作 | 補足 |
|---|---|---|
| `R` | 校正対象 ⇄ 比較資料（**R**eference） | REF が無い指摘では短いトーストで知らせる |
| `C` | 指摘ページ ⇄ 相手側ページ（**C**ounterpart）。相手が複数なら順に回る | |
| `Backspace` または `Alt+←` | 1つ前の表示へ戻る（P1-3 の履歴） | 入力欄にいるときは `reportTypingTarget`（`:10191`）で除外 |
| `Esc` | 表示設定を閉じる → 閉じていれば対象の指摘ページへ戻る | 今は表示設定を閉じるだけ |
| `PageUp` / `PageDown` | 表示中の文書でページ送り（P1-4） | ← → は指摘の移動のまま |

- ガードは既存の `reportNavKeyDelta` と同じ規則（修飾キーなし、入力中は無効）にする。
- `alert()` のキー一覧は、表示設定ポップオーバーと同じ DOM ポップオーバーに置き換える。`?` キーでも開けるようにする。
- トグルボタンの `title` にキーを書く（例「比較資料（R）」）。

### P0-3 文書ごとに表示位置を覚える（F6）

- `viewState = { target: {page, scrollTop, scrollLeft}, 'ref:1': {...} }` を持ち、切り替える直前に今の `pdfWrap.scrollTop/Left` を保存、切り替え後に復元する。
- `renderPdfPage` の `if(viewKey!==lastViewKey)pdfWrap.scrollTop=0` は、「保存済みの位置が無いときだけ先頭へ」に変える。
- 自動スクロール（`scrollFirstActiveHighlightIntoView`）との優先順位:
  - **指摘を選び直したとき**（`setActive`）: ハイライトへ寄せる（今と同じ）。
  - **同じ指摘のまま R で往復したとき**: 保存した位置を戻す。ユーザーが自分でスクロールしたなら、その位置を尊重する。
- ズームは今の共有のままでよい（日英で同じ倍率の方が比べやすい）。ただし「幅」モードは文書ごとに文字範囲が違うので、`FIT_CACHE` のまま文書別に計算する（今と同じ）。

### P0-4 REF を先に読み込み、待っていることを見せる（F7）

- 最初の描画が終わったら `requestIdleCallback`（無ければ `setTimeout`）で `refDocPromise(1)` を先に呼ぶ。REF を使わない人も多い（コメント `:10025`）ので、**待ち時間を前倒しするだけ**で、描画の優先度は対象PDFより下げる。
- 読み込みが終わるまでは、トグルの比較資料側に「読み込み中…」と小さなスピナー。PDF 枠には半透明のオーバーレイを出し、二度押しを防ぐ。

### P1-1 「比較資料を表示したまま次の指摘へ」モード（F4）

- 案A（おすすめ）: トグルの状態を **選択中の指摘より優先** させる。REF 表示中に → を押したら、次の指摘の REF 側（`reference_highlight_page`）を開く。REF の無い指摘では対象側に自動で戻し、「この指摘は比較資料なし」と出す。
- 案B: 表示設定に「指摘を移動しても比較資料の表示を保つ」チェックを置く。案Aの挙動が意外だと感じる人向けの逃げ道として、案Aと一緒に用意してもよい。
- 実装の要は `setActive` の `viewRefIndex=0` を「保持モードでなければ 0」に変えること。
- 整合性レビューでは、→ だけで「日本語側の該当箇所」を順に見られるようになり、1件あたり往復 2 クリックの操作が要らなくなる。

### P1-2 並べて表示（スプリットビュー）（F9）

- `.pdfbar` に `[並べて表示]`。`.page-pane` を上下2段（対象が上、REF が下）にする。横幅が 46% なので、左右に割ると読めない。
- 必要なもの: canvas とハイライトレイヤーを2組、`renderToken` と `renderTask` を文書ごとに持つ。今の `cancelActiveRender` は1本だけ前提。
- 左右に並べたい人向けに、右ペインをたたむボタン（`.main` の列を `1fr 0` に）を一緒に付けると、横並びにする幅を確保できる。
- 表示設定に保存する（P2-3）。
- 工数は一番大きいが、数値・語順の見比べ（このツールの主な用途）にはいちばん効く。P0 群が済んだあとの本命。

### P1-3 表示の履歴と「戻る」（F11, F13）

- `viewHistory` スタックに `{doc, page, scrollTop, recordNo}` を積む。積むのは REF への切替、相手側へのジャンプ、ページ送りのとき。指摘の移動（← →）では積まない。
- `.pdfbar` 右端の `↩ 戻る`（`Backspace` / `Alt+←`）で1つ戻す。履歴が空なら無効にする。
- 相手側ジャンプ（`.jump-counter`）にも、戻り先として「P.12 に戻る」を出す。今は対象内の相手側ジャンプだけ戻る手段が無い。

### P1-4 表示中の文書でページを送る（F8, F12）

- `.pdfbar` の `P.12` を `◀ [12] / 40 ▶` にする（数字は入力できる）。REF 表示中は REF のページ数。
- 指摘のページから離れたら、ラベルの横に `指摘は P.12 ・戻る` のバッジを出す（F12）。ページ選択リストは「いま表示しているページ」ではなく「選択中の指摘のページ」だと分かるラベルにする。
- REF でモデルが挙げたページがずれていたときに、自分で隣を確かめられる。`reference_highlight_status==='page-only'` のときは、これが唯一の手段になる。

### P1-5 切替ボタンの場所を固定する（F14）

- `[比較資料 P.N]` と `[P.8 も表示]` を詳細の **見出し行**（`master-detail-head`、◀ n/N ▶ の隣）にまとめ、`理由・詳細` の中からは外す。
- P0-1 のツールバーのトグルがあれば、詳細側のボタンは「どのページへ飛ぶか」の情報表示に役割を絞れる。

### P2-1 押している間だけ比較資料を見る（チラ見）

- `Space` を押している間だけ REF を表示し、離すと対象に戻る。位置は P0-3 で戻す。
- 同じ位置で素早く見比べられ、数字の違いに気づきやすい。並べて表示（P1-2）より安く作れる代わりの手段。
- `Space` は `#pdfWrap` のスクロールと重なるので、PDF 枠にフォーカスがあるときだけ有効にするか、別のキーを選ぶ。

### P2-2 位置が分からない REF ページで、探す文字列を見せる

- `reference_highlight_status==='page-only'` のときは、PDF 枠の上に `reference_quote` を薄い帯で出し、[コピー] を付ける。canvas の上では Ctrl+F が効かないため。
- 将来 PDF.js のテキストレイヤーを載せれば、ページ内検索もできる。

### P2-3 表示の好みを覚えておく

- ズーム、P1-1 の保持モード、P1-2 の並べて表示、文字サイズを、確認状況と同じ保存先（`確認状況.json` / `/__report-state`、無ければ localStorage）に残す。localStorage はポートごとに分かれるので、サーバー側を優先する（コメント `:10126` と同じ理由）。
- 開き直したら前回の指摘と文書（対象/REF）に戻る。

### P2-4 比較資料を別タブで開く

- 表示設定の `[元PDFを開く]` の隣に `[比較資料を開く]`。`pdfUrlFor` は対象専用なので、REF 用の blob URL と `#page=` を作る。モニターが2枚ある人は、Edge の2窓で並べられる。

### P2-5 狭い画面

- 縦積みのレイアウト（`:9938`）では、トグルとページ送りが画面外に流れないよう `.pdfbar` を `position:sticky` にする。

## 6. 実装時の注意

- レポートは `index.html` 内の **テンプレート文字列** として生成される。`\\n` などのエスケープ、`${...}` の展開に注意する。`Test-IndexHtmlSyntax.mjs` と `Test-ReportRender.mjs` で、生成後の HTML の構文を確かめる。
- 既存の UI テストに影響しそうなもの: `Test-ReferenceViewer.mjs`、`Test-ReportDesign.mjs`、`Test-Issue190ReportReadability.mjs`（前後移動の導線を1組にした #190 の方針。新しいキーはこれと矛盾させない）、`Test-ResultsWorkbenchLayout.mjs`、`Test-CanvasRenderRace.mjs`（P1-2 で描画タスクを2本にするとき）。
- #190 の「前後移動は ◀ n/N ▶ と ← → だけ」という方針は守る。ここで足すページ送りは **表示中の文書のページ** で、指摘の移動とは別だと見た目で分かるようにする（場所は `.pdfbar`、アイコンも変える）。
- 確認済みの保存（`persistDone`）と同じ保存先に表示の状態を混ぜるときは、`exported_at` が違うファイルを読まない既存の規則に合わせる。
