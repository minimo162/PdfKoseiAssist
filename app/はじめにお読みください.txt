PDF校正アシスト ― はじめにお読みください
バージョン: v95.5

英語に訳したPDFを Microsoft Copilot に読ませて、
誤りの候補を一覧にするアプリです。
まず下の4つ（1〜4）を読めば使えます。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. 最初に1回だけ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 1) 共有フォルダにある
    「PDF校正アシスト_初回セットアップ.cmd」をダブルクリックします。
    共有フォルダの場所は管理者が案内します。自分のパソコンに
    コピーせず、共有フォルダに置いたまま開いてください。
    初回は、アプリを自分のパソコンに準備するため、
    画面が出るまで数十秒ほどかかることがあります。
 2) Copilot には、Windows にサインインしている会社のアカウントで
    自動でつながります。ふつうは何もしなくて構いません。
    自動でつながらなかったときだけ、このアプリ専用の Edge が開きます。
    そこで会社のアカウントで Microsoft 365 にサインインしてください。
    画面右下の小さい画面は、サインインが済むと自動で閉じます。
 3) 「準備ができました」と出たら完了です。

 ◇ Copilot に送るもの（使う前に知っておいてください）
  このアプリは、パソコンの中だけで動くものではありません。
  PDFのファイルそのものではなく、本文の文字と校正の指示を、
  会社のアカウントの Microsoft Copilot に送ります。
  金額・数値は記号に置き換えてから送り、元の数値に戻す処理は
  このパソコンの中で行います（詳しくは後ろの「社外（Copilot）へ何を送るか」）。
  どの資料に使ってよいかは、社内のルールに従ってください。

 右クリックの「送る」に「PDF校正アシストで校正」が加わります。
 新しい版への入れ替えは管理者が共有フォルダで行います。
 利用者は何もしなくて構いません（次に使うときに新しい版になります）。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. 毎回の使い方（「送る」で校正）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 1) 英文のPDFと、日本語の原稿のPDFを同じフォルダに置きます。
 2) 2つを選んで右クリック →「送る」→「PDF校正アシストで校正」。
    英文だけで見るときは、英文のPDFを1つだけ選びます。
    Windows 11 では、右クリック →「その他のオプションを確認」
    （または Shift＋右クリック）の中に「送る」があります。
 3) どちらが英文か自動で分からないときは、組み合わせを選ぶ画面が出ます。
    「校正する英文PDF」と「比較する日本語原稿」が正しい方を押してください。

 ・初めて使うときは、画面右下に進み具合の小さな画面が出ます。
   閉じても校正は続きます。
 ・もう一度見るときは、画面右下のタスクトレイのアイコンを
   右クリック →「進み具合を表示」（ダブルクリックでも出ます）。
   アイコンが見当たらないときは、右下の「^」を押すと、
   隠れているアイコンが出ます。
 ・やめたいときは、進み具合の画面の「校正を中止」、または
   アイコンを右クリック →「中止」。途中までの結果は保存されません
   （元のPDFは変わりません）。
 ・終わると、どのPDFの結果か・どこに保存したかを書いた通知が出て、
   結果が自動で開きます。通知はあとから通知センターでも見られます。
   通知を切っていても、校正はそのまま進みます。

■ 3. 結果の見方・渡し方
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ◇ 結果のできる場所
  元のPDFと同じフォルダに「（英文PDFの名前）_校正結果」
  というフォルダができ、Edge で自動で開きます。
  同じ名前があるときは「 (2)」などの番号を付けて残します。
  一部のページを確認できなかったときは、名前の最後に
  「_一部未完了」が付きます。
  元のフォルダに保存できないときは、ドキュメントの
  「PDF校正アシスト結果」に保存し、通知でお知らせします。

 ◇ 開き直すとき
  結果フォルダの「指摘レポートを開く.cmd」をダブルクリックします。
  中の HTML ファイルを直接開かないでください。

 ◇ 画面の見方
  左に元のPDF、右の上に「いまの指摘」、その下に指摘の一覧が
  並びます。一覧の行を選ぶか、← → キーで順に進みます。
  指摘を選ぶと、PDFの該当箇所が黄色い枠で囲まれます。
  「原文」と「置き換え候補」は、直すところだけ赤字で示します
  （消す文字は取り消し線、入れる文字は下線）。
  見終わったら「確認済み」を押します（一覧の右端の丸でも付けられます）。
  印は結果フォルダの中に保存され、次に開いたときも残ります。
  文字の大きさ・印刷・元PDFを開く操作は、右上の「表示設定」にあります。

 ◇ 「置き換え候補」と「確認すること」（ここが一番大事です）
  指摘ごとに、原文の下にどちらかが出ます。
  ・置き換え候補（英文）… 直した英文の候補です。内容を確認し、
    採用する場合は元の資料に反映してください。
    「候補文をコピー」で英文だけをコピーできます。
  ・確認すること（日本語）… 直し方の説明です。
    （例:「3,860と3,680のどちらが正しいか確認する」）
    どちらが正しいかはこのアプリでは決められないので、
    人が調べて直してください。
    この日本語を、そのまま英文に貼らないでください。

 ◇ 人に渡すとき
  結果フォルダを丸ごと共有フォルダに置き、相手に
  「指摘レポートを開く.cmd」を実行してもらいます。
  フォルダの中身を分けずに渡してください。
  「確認済み」の印も一緒に渡ります。
  メールで送るときだけフォルダを ZIP にし、受け取った人には
  「すべて展開」してから .cmd を実行してもらいます。

■ 4. 困ったとき
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ◇ 「送る」の中に「PDF校正アシストで校正」が無い
  共有フォルダの「PDF校正アシスト_初回セットアップ.cmd」を実行してください。
  共有フォルダの場所が変わったときも、新しい場所のものを実行して
  「登録し直す」を押せば直ります。

 ◇ 「配布フォルダ（…）に接続できませんでした」と出た
  社内ネットワーク（社外からは VPN）につないでから、もう一度実行します。
  一度使ったパソコンなら、つながらないときも前の版で動きます。
  このメッセージは、まだ一度も準備が済んでいないときだけ出ます。

 ◇ 「配布フォルダが更新中のため、準備できませんでした」と出た
  管理者が新しい版を置いている途中です。数分待ってから、
  もう一度実行してください。

 ◇ 「Copilot にサインインしていません」と出た
  初回セットアップを実行します。「登録済みです」と出たら
  「登録し直す」を押し、開いた Edge でサインインしてから、
  もう一度「送る」を実行してください。

 ◇ 「Edge の Copilot 画面を一度クリックしてください」と出た
  出てきた Edge の画面を一度クリックしてください。
  クリックすると校正が続きます。

 ◇ 「日本語のPDFのようです」と出た
  日本語の原稿だけを選んでいます。英文のPDFを選んで
  （日本語の原稿と2つ選んでも構いません）、もう一度「送る」を実行します。

 ◇ 「PDFを読み込めませんでした」と出た
  パスワード付きのPDFや、壊れているPDFは校正できません。
  PDFが開けるか確かめてから、もう一度「送る」を実行します。

 ◇ 「別の版のアプリが起動中です」と出た
  違う版のアプリの画面が開いたままです。その画面右上の
  「アプリを終了」を押してから、もう一度「送る」を実行します。

 ◇ 「別の校正を実行中です」と出た
  前の校正がまだ終わっていません。トレイのアイコンを右クリック →
  「進み具合を表示」で進み具合を見て、終わってからもう一度「送る」を
  実行します。急ぐときは、アイコンを右クリック →「中止」でやめられます。

 ◇ 「一部の範囲を確認できませんでした」と出た
  結果は開けますが、見られなかったページがあります。
  時間をおいて、もう一度「送る」を実行してください。

 ◇ 終わったのにレポートが開かない
  元のPDFと同じフォルダ（または、ドキュメントの
  「PDF校正アシスト結果」）の「〇〇_校正結果」を開き、
  「指摘レポートを開く.cmd」をダブルクリックしてください。

 ◇ HTML を開いたら「このファイルは直接開けません」と出た
  同じフォルダの「指摘レポートを開く.cmd」から開いてください。
  ZIP の中にあるときは、先に「すべて展開」します。

 ◇ 「送る」から外したい
  初回セットアップを実行し、「「送る」から削除する」を選びます。

 ◇ 新しい版にしたい
  利用者の作業はありません。管理者が共有フォルダを更新すると、
  次に「送る」やアプリを起動したときに新しい版になります。
  アプリの画面を開いたままのときは、「アプリを終了」で閉じたあと
  の起動から新しい版になります。

 ◇ どれにも当てはまらない
  出たメッセージをそのまま控え、次のフォルダの中身を
  管理者に渡してください。
    %USERPROFILE%\.pdf-kosei-ps\logs
  （エクスプローラーのアドレス欄に貼ると開けます）

■ 詳しい情報
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 画面で確認しながら校正したいとき

 1. 共有フォルダの「PDF校正アシスト起動.cmd」をダブルクリックします。
    ブラウザが開くまで少し待ってください。準備中は画面を
    いったん隠しています。時間がかかるときはエラー画面が出ます。
 2. 自動でサインインできなかった場合は、画面上部の「Copilot画面を表示」
    を押してサインインします。一度済ませれば次回からは不要です。
 3. 「PDFを選ぶ」の左側に、英訳したPDFを置きます。
    日本語の原稿PDFがあれば、右側の「日本語の原稿PDFを追加（任意）」に置きます。
 4. 一部のページだけを見るときは「設定を変更（任意）」を開き、
    ページを入力します（ふだんは不要です）。
 5. 「校正を開始」を押します。あとは自動で進みます。
    経過と残りの見込みが画面に出ます。
 6. 終わると、下の「指摘を確認する」に結果が並びます。
    じっくり見るときは「レポートを保存（フォルダ）」で保存し、
    保存したフォルダの「指摘レポートを開く.cmd」で開きます。
    対応していないブラウザーでは ZIP 保存に切り替わります。
    CSV も保存できます（「その他の保存」）。Excel で開けます。
 7. 終了するときは、画面右上の「アプリを終了」を押します。
    校正中なら先に止めてから終了します。止められない処理が
    残っているときは、終了せずに理由を表示します。

 「PDF校正アシスト起動.cmd」にPDFをドロップしても、
 「送る」と同じ校正ができます。ただし & % ^ などを含む
 場所のファイルは、「送る」を使ってください。


■ 「校正」で何をしているか

 3段階で見ます。どの結果も同じ一覧に並びます。

 1段目 … 文書全体を見て、英文の中の食い違いを探します。
          （同じ数値が2箇所で違う、訳語が揃っていない、など）
          日本語の原稿が無くてもここは動きます。
 2段目 … もう一度、文書全体を見直します。
 3段目 … 日本語の原稿と1ページずつ突き合わせます。
          訳抜け・誤訳・数値の取り違えを見ます。
          日本語の原稿が無いと、英文だけを1ページずつ見ます。

 1・2段目では、ほとんどが「確認すること」（日本語の説明）になります。
 食い違いは見つけられても、どちらが正しいかまでは
 決められないためです。

 出てきた指摘は、次の点をこのアプリで確かめてから出しています。
  ・引用した英文が、本当にその原文にあるか
  ・同じ値を「食い違っている」と言っていないか（単位まで見ます）
  ・置き換え候補が原文と同じになっていないか
 引っかかったものは誤指摘と判断し、一覧から外しています。
 外した件数と理由はレポートの「このレポートについて」に出し、
 外した指摘も結果フォルダの _data の 指摘.csv・指摘.json に残します。
 どちらの値が正しいかの判断と、一覧に無い誤りの有無は、
 このアプリでは分かりません。確かめる場所を絞るための道具です。


■ 結果フォルダの中身

 「指摘レポートを開く.cmd」と、表示に必要な _data フォルダが
 入っています。元のPDFも _data の中にあります。
 「確認済み」の印は _data\確認状況.json に保存されます。
 _data を移動・削除すると開けなくなるので、フォルダごと扱います。
 レポートは、このパソコンの中だけで動く仕組みで Edge に開きます。
 タブを閉じると自動で終わります。


■ どれくらい時間がかかるか

 手元の実測では、15ページ・Copilot への依頼12件で約1分半でした。
 ページ数が多いほど長くなり、Copilot の混み具合でも変わります。
 画面で校正するときは「経過」と「残り およそ」が出ますので、
 そちらを目安にしてください。


■ 社外（Copilot）へ何を送るか

 送るのは、校正する範囲の本文の文字と、校正の指示だけです。
 日本語の原稿を使うときは、その本文の文字も送ります。
 PDFのファイルそのものは送りません。
 金額・数値は ⟦#ABC⟧ のような記号に置き換えてから送ります。
 記号を元の数値に戻す処理と、その対応表の保存は、
 このパソコンの中だけで行います。


■ 共有フォルダでの配布とアップデート（管理者向け）

 利用者は共有フォルダの入口（初回セットアップ・起動.cmd・「送る」）から
 使います。アプリはそのたびに共有フォルダの版を確かめて、
 利用者ごとの %LOCALAPPDATA%\PdfKoseiAssist に写してから動きます。
 共有フォルダは、利用者から読めれば足ります（書き込み権限は不要です）。

 新しい版にするとき:
 1. 新しい版の中身（PDF校正アシスト_初回セットアップ.cmd・
    PDF校正アシスト起動.cmd・はじめにお読みください.txt・_app フォルダ）を、
    共有フォルダへ上書きでコピーします。利用中の人がいても構いません。
 2. 利用者は、次に「送る」やアプリを起動したときに新しい版で動きます。
    アプリの画面を開いている人は、閉じたあとの起動から新しい版になります。
 3. コピーの途中に起動した人は、前の版のまま動きます。
    中身がそろわない版で動くことはありません。

 設定（_app\config\settings.json）は共有フォルダのものが使われます。
 書き換えると、利用者が次に起動したときに反映されます。

 「送る」から外すときは、初回セットアップを実行し、
 「「送る」から削除する」を選びます。そのあと、自分のパソコンに
 写したアプリ（%LOCALAPPDATA%\PdfKoseiAssist）を削除して構いません。
 セットアップを実行できない場合は、
 %APPDATA%\Microsoft\Windows\SendTo にある
 「PDF校正アシストで校正.lnk」を削除してください。


■ さらに詳しいトラブル対応（管理者向け）

 起動しない、画面が白いまま、「Copilot準備中」から進まない、
 などの技術的な対応は、共有フォルダの _app にある README.txt にあります。
 管理者向けの内容なので、分からないときは管理者に渡してください。
